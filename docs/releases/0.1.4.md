# 敬語ボタン 0.1.4

書き換え結果を見比べながら、追加の指示で自然に調整できるようになりました。アップデートのお知らせとサインイン画面も、見つけやすさと安心感を改善しています。

- 結果画面の ↻ にカーソルを合わせると、その場で「もう少し短く」「より丁寧に」などの追加指示を入力可能に
- 再生成した結果を `1 / 1`、`2 / 2` のように保持し、左右の矢印で以前の文章へ戻れるように改善
- 過去の結果を表示したまま、コピー・評価・挿入・再調整できるように対応
- 新しいバージョンが見つかったとき、敬語ボタンの上、メニューバー、ホーム画面の3か所から確認できるお知らせを追加
- Google サインインの接続先表示を `auth.keigobutton.com` に変更し、公式デザインのGoogleボタンに統一
- 英語・日本語・简体中文それぞれで、利用状況やプラン画面の日付表示が自然になるよう修正
- 結果画面の入力ヒント、送信ボタン、枠線、各種ボタンの細かな表示崩れを修正
