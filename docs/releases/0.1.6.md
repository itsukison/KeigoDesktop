# 敬語ボタン 0.1.6

## 日本語

アップデートをより早く見つけられるようにし、初回セットアップと画面表示の細かな問題を修正しました。

- 新しいバージョンを、起動時・Macの復帰時・1時間ごとの確認で、これまでより早く案内できるように改善
- 返信モードで待機している間も、安全なタイミングでアップデートを確認できるように修正
- 初回セットアップの「あとで始める」がセットアップ全体を終了せず、現在の練習だけをスキップして次へ進むように修正
- 言語選択、用途選択、プランカード、設定の入力欄などで、色付きの枠線が角だけ二重または不均一に見える問題を修正
- メイン画面と初回セットアップのブランドアイコンを、macOSのアプリアイコンと統一

## English

This update finds new versions sooner and fixes several onboarding and visual details.

- Checks for new versions at launch, when your Mac wakes, and every hour so updates appear sooner
- Allows safe update checks while Reply Mode is armed by a copied message
- Fixes “Start later” in onboarding so it skips only the current practice instead of ending the entire setup
- Fixes colored outlines that could look doubled or uneven at the corners on language, purpose, plan, and settings controls
- Aligns the brand icon in the main window and onboarding with the macOS app icon

## 简体中文

此版本可以更快发现新版本，并修复了首次设置和界面显示中的一些细节问题。

- 在应用启动、Mac 唤醒以及每小时检查新版本，让更新提示更及时
- 回复模式等待已复制消息时，也可以在安全的时机检查更新
- 修复首次设置中的“稍后开始”：现在只会跳过当前练习，不会直接结束整个设置流程
- 修复语言、用途、套餐卡片和设置输入框等控件的彩色边框在圆角处看起来重叠或粗细不均的问题
- 统一主窗口、首次设置与 macOS 应用图标中的品牌图标
