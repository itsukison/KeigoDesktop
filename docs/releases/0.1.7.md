# 敬語ボタン 0.1.7

## 日本語

返信とメールであなたの名前が正しく使われるようになり、1日あたりの利用制限を撤廃しました。

- 初回セットアップで「メッセージで使う名前」を必ず設定するように変更。返信モードが自分宛ての呼びかけを正しく見分け、メールの結びにも適切な名前を使えるようになります
- 1日あたりの利用上限を撤廃。月の利用可能回数は、1日にまとめて使っても、少しずつ使っても構いません
- 名前の入力例を各言語に合わせて表示（日本語は「山田 太郎」、English は「John Smith」、简体中文 は「张三」）

## English

Replies and emails now use your name correctly, and the daily usage limit is gone.

- Setup now asks for the name you use in messages. Reply Mode uses it to tell when a message is addressed to you, and to sign emails with the right name
- Removed the daily usage limit. Your monthly rewrites are yours to spend all at once or a few at a time
- Name examples now match the language you are using — 山田 太郎 in Japanese, John Smith in English, 张三 in Chinese

## 简体中文

回复和邮件现在能正确使用你的名字，同时取消了每日使用上限。

- 首次设置现在会要求填写“你在消息中使用的名字”。回复模式据此识别消息何时在称呼你，并在邮件署名时使用正确的名字
- 取消每日使用上限。每月可用的改写次数，你可以一次用完，也可以慢慢使用
- 名字示例改为符合各语言的习惯——日语为「山田 太郎」，英语为 John Smith，中文为「张三」
