# 敬語ボタン 0.1.2

表示言語を選べるようになり、画面下のバーとアップデート案内もより使いやすくなりました。

- 日本語、English、简体中文の3言語に対応
- 初回セットアップの先頭と環境設定から表示言語を変更可能に
- 英語向けのボタンセットと、英語の文章に合った書き換え指示を追加
- 中国語表示では、日本語を書くためのボタンをそのまま利用
- メイン画面、オンボーディング、画面下のバー、メニューバーの表示を各言語に対応
- バーを初めて開くときの引っかかりと、縦横が別々に動く展開アニメーションを改善
- 新しいバージョンをホーム画面で静かに案内し、Sparkleの更新画面へ進めるように改善
