# 敬語ボタン 0.1.3

Proプランを米ドルでも購入できるようになり、初回セットアップの最後に期間限定のウェルカムオファーが追加されました。

- 英語表示のときは米ドルで購入可能に（月払い $12、年払いは $10 / 月相当・年額 $120）
- 日本語・简体中文の表示では従来どおり円建て（月払い ¥1,480、年払いは ¥1,200 / 月相当）
- 表示している価格がそのまま請求される金額になるよう、通貨をアプリ側から明示
- 初回セットアップの最後に、初回3ヶ月または初年度が33%オフになるウェルカムオファーを追加（72時間限定）
- オファーの受付期間中は、ホーム画面のカードから同じ価格と残り時間を確認可能に
- プラン画面を通貨と割引に対応させ、年払いを既定の選択に変更
- サインアップとサインインの計測を追加し、今後の品質改善に必要な診断情報を整備
