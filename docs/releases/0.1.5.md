# 敬語ボタン 0.1.5

入力欄を選んでいないときでも、文章作成や返信をすぐに始められるようになりました。結果の書き込み先も、そのときの状態に合わせて分かりやすく切り替わります。

- ✎ から、入力欄や元の文章がない状態でも新しいメッセージを作成可能に
- コピーしたメッセージへの返信を、返信先の入力欄を先に選ばなくても作成できるように改善
- 結果画面の操作を、書き込める入力欄があるときは「挿入」、ないときは「コピー」へ自動で切り替え
- 結果を表示したまま入力欄をクリックすると「挿入」に切り替わり、書き込みに失敗した場合も文章をクリップボードへ安全に保存
- 結果画面が消える、入力欄の選択によって高さが変わるなどの表示上の問題を修正
- 返信相手と自分を取り違えないよう返信文の生成を改善し、必要な場合だけ自然に名前やメールの結びを使用
- 英語で文章を書く設定とボタンの言語を正しく連動させ、作成済みのカスタムボタンを残したまま言語セットを変更可能に
