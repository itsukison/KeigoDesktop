# 敬語ボタン 0.1.10

## 日本語

案内を分かりやすくし、どの書き換え機能が役立っているかを把握するための内部計測を改善しました。

- 書き換える文章が見つからないとき、入力欄をクリックする・文章を選択する・✎ から新しく書く、という次の操作を分かりやすく案内するようにしました
- 保存ボタンの用途と、初回設定で選ばれたボタンセットを、個人の文章を含まない固定カテゴリで記録するようにしました
- 文章を読み取れなかった場合、どのアプリで起きたかをアプリ識別子だけで記録し、対応アプリの改善に役立てられるようにしました

内部の計測に、ボタン名、指示文、書き換え前後の文章が含まれることはありません。

## English

This update makes recovery guidance clearer and improves the internal measurements used
to understand which rewrite features are useful.

- When no text can be found, the message now clearly explains the available next steps:
  click into the field, select text, or use ✎ to write something new
- Saved-button purposes and the button pack chosen during setup are now measured with
  fixed, privacy-safe categories
- If text capture fails, the app records only the application identifier so compatibility
  problems can be diagnosed by app

These measurements never include button names, instructions, or text before or after a
rewrite.

## 简体中文

本次更新让错误提示更清楚，并改进了用于了解哪些改写功能真正有用的内部统计。

- 找不到可改写文字时，现在会明确提示下一步：点击输入框、选中文字，或使用 ✎ 新写一段文字
- 现在会使用不含个人文字的固定类别，统计保存按钮的用途和首次设置时选择的按钮组合
- 读取文字失败时，只记录发生问题的应用标识符，以便改善不同应用中的兼容性

内部统计不会包含按钮名称、指令内容，也不会包含改写前后的文字。
