# Four-button onboarding — initial prompt examples

> Superseded for prompt review by [main button output choices](main-button-output-options.md). Only the essential four are now offered per writing language; the extra packs below are historical catalog entries retained for saved configurations. Before/After content has been removed from customization. Prompt wording awaits output-choice feedback.

New preset selections use one short instruction per button. Existing saved buttons are not migrated. Examples below are illustrative copy, not live model results. Japanese and Chinese interfaces share the Japanese writing presets.

## Japanese

| Button purpose | Instruction | Example input → output |
|---|---|---|
| 敬語 | 自然で丁寧な敬語にしてください。 | 明日の会議、15時に変えて。 → 明日の会議を15時に変更していただけますか。 |
| メール | そのまま送れる日本語のビジネスメール本文に整えてください。 | 資料ありがとう。確認して金曜までに返事します。 → 資料をお送りいただき、ありがとうございます。 / 内容を確認し、金曜日までにご連絡いたします。 |
| 英訳 | 自然な英語に翻訳してください。 | 来週の火曜の午後は空いていますか？ → Are you free next Tuesday afternoon? |
| 自然に / 自然な日本語 | 自然で読みやすい日本語に整えてください。 | この案について、あなたの考えを聞くことができたら嬉しいです。 → この案について、ご意見を聞かせていただけると嬉しいです。 |
| 社内チャット | 社内チャット向けに、簡潔で感じのよい文章にしてください。 | 確認まだの人、今日中に見てほしいです。 → 未確認の方は、今日中に確認をお願いします！ |
| 上司向け | 上司に伝わる、簡潔で丁寧な文章にしてください。 | 明日午前休みたい。午後から出ます。 → 明日の午前中、お休みをいただけますか。午後から出勤します。 |
| 取引先 | 取引先に送れる、丁寧で分かりやすい文章にしてください。 | 見積もり送ります。確認してください。 → お見積もりをお送りします。ご確認いただけますと幸いです。 |
| 会議要約 | 会議メモを、決定事項と次にやることが分かるように要約してください。 | 公開は金曜。田中さんが木曜までに文章確認。価格はまだ決まってない。 → 決定：金曜日に公開。 / 次の作業：田中さんが木曜日までに文章を確認。 / 未決：価格。 |
| 和訳 | 自然な日本語に翻訳してください。 | Could we move the meeting to Friday? → 打ち合わせを金曜日に変更できますか？ |
| 仕事英語 | 仕事でそのまま使える、自然で丁寧な英語にしてください。 | 修正版を送ります。金曜までに確認をお願いします。 → Here's the revised version. Could you review it by Friday? |
| 友達英語 | 友達に送る、自然で親しみやすい英語にしてください。 | 明日、時間あったらコーヒー飲まない？ → Want to grab a coffee tomorrow if you’re free? |
| 校正 | 日本語の誤字や文法の誤りを直してください。 | 明日は15時からで大丈夫でしょか。 → 明日は15時からで大丈夫でしょうか。 |
| やさしく | やさしく分かりやすい日本語にしてください。 | 関係各所との調整後、対応方針を共有します。 → 関係者と相談してから、どう対応するかをお伝えします。 |
| LINE | LINEで送る、短く自然なメッセージにしてください。 | 明日の予定ですが、15時にお会いする形でよろしいでしょうか。 → 明日15時に会うので大丈夫？ |
| 友達 | 友達に話すような、自然で親しみやすい文章にしてください。 | 本日はお時間をいただきありがとうございました。またお会いしましょう。 → 今日はありがとう！また会おうね。 |
| SNS投稿 | SNSの投稿として、読みやすく伝わる文章にしてください。 | 新機能できました。文章選んで押すと整います。試してね。 → 新機能を公開しました！ / 文章を選んで、ボタンを押すだけで整えられます。ぜひ試してみてください。 |
| コメント | SNSで気軽に送れる、感じのよいコメントにしてください。 | この写真いい。どこで撮った？ → 素敵な写真ですね！どちらで撮られたんですか？ |

## English

| Button purpose | Instruction | Example input → output |
|---|---|---|
| Polite | Make this sound polite and natural. | Send me the file today. → Could you send me the file today, please? |
| Email | Turn this into a clear, professional email body. | thanks for the proposal. ill review it and reply friday. → Thanks for sending the proposal. / I’ll review it and get back to you by Friday. |
| Shorten | Make this shorter while keeping the main points. | I just wanted to ask whether it might be possible to meet sometime on Friday. → Could we meet on Friday? |
| Proofread | Fix spelling and grammar while keeping my voice. | She dont know if its ready yet. → She doesn’t know if it’s ready yet. |
| Chat | Make this clear and friendly for a work chat. | review still missing. need it today. → Could someone finish the review today? Thanks! |
| Manager | Make this clear and respectful for my manager. | need tomorrow morning off. back after lunch. → Could I take tomorrow morning off? I’ll be back after lunch. |
| Client | Make this clear and professional for a client. | sending the estimate. have a look. → Here’s the estimate for your review. |
| Recap | Summarize these notes into decisions and next steps. | launch friday. sam checks copy thursday. price undecided. → Decision: Launch Friday. / Next step: Sam reviews the copy Thursday. / Open question: Pricing. |
| Follow-up | Write a friendly follow-up. | checking on the quote i sent last week. → Just following up on the quote I sent last week. Have you had a chance to look it over? |
| Intro | Turn this into a friendly introduction with a clear ask. | hi, we built a writing tool. want a demo this week? → Hi, we’ve built a tool to help with everyday writing. Would you be interested in a demo this week? |
| Persuade | Make this more persuasive using the ideas already here. | use the template. it saves setup time. → Save time on setup by starting with the template. |
| Decline | Help me say no politely and clearly. | cant take this on. my quarter is full. → Thanks for thinking of me. I’m fully booked this quarter, so I’ll have to pass. |
| Grammar | Fix the grammar and spelling. | We has finish the report yesterday. → We finished the report yesterday. |
| Natural | Make this sound natural in English. | Please let me know your convenient time. → Please let me know what time works for you. |
| Simplify | Make this easy to understand in plain English. | We will commence implementation following stakeholder alignment. → We’ll start once everyone involved agrees. |
| Formal | Rewrite this in a formal, professional tone. | we cant finish friday. moving it to monday. → We are unable to complete this by Friday. Completion has been moved to Monday. |
| Friendly | Make this warm and conversational. | I would appreciate an update when you have availability. → Could you give me an update when you get a chance? |
| Post | Turn this into an engaging, readable social post. | new feature today. select text press button. give it a go. → New today: select your text, press a button, and give your writing a polish. Try it out! |
| Comment | Make this a friendly, thoughtful public comment. | good explanation. the example helped. → Great explanation! The example really helped it click. |
| Casual | Make this relaxed and natural for a friend. | I regret to inform you that I will arrive fifteen minutes late. → Sorry, I’m running 15 minutes late! |

## Native implementation and verification

The selection page follows the landing hero’s composition: native writing surfaces over the supplied mountain artwork, with a compact dark bar beneath. The review page has full-row selectors, an editor bound to each button’s identity, and before/after examples. Reordering retains the selected button; customizing an instruction hides its stock example.

- [Selection screen](four-button-onboarding/choose-buttons.png)
- [Customization screen](four-button-onboarding/edit-buttons.png)
- Native Debug build passed (`CODE_SIGNING_ALLOWED=NO`).
- 89 focused onboarding, localization, saved-button, stock-language and analytics tests passed; 4 new example/legacy-recognition tests passed.
- Rendered both changed screens at 1080 × 700 points / 2× in Japanese, English and Simplified Chinese. Inspected the selection and review layouts, then reduced editor/list spacing so the starter examples and Add button fit without scrolling.
- In the isolated native preview, selected and independently edited Email, Shorten and Proofread, switched between them, and verified their edits persisted. Moving Email into the first position preserved its instruction and updated the main-button label.
- Live generation, account saving/sync and cross-app insertion were not exercised. The examples are editorial illustrations, not measured model outputs. System accessibility preferences and a full VoiceOver walkthrough were not changed or tested.

Debug inspection: launch the built executable with `--inspect-button-setup`. It uses the existing empty-session preview model and in-memory replay drafts. Rendering remains available through `--render-aside-previews`.
